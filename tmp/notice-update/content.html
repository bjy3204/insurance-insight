보험인사이트가 새롭게 개편되었습니다! 😊

전체적인 디자인과 메뉴 구성을 정비하고, 반복적인 문서 작업을 줄일 수 있도록 다양한 편의 기능을 추가했습니다

📌 01. 고객관리 페이지 전면 개편

기존 개인공간 메뉴를 새로운 고객관리 페이지로 개편했습니다

  • 엑셀 파일로 기존 고객정보 한 번에 등록
  • 구글 스프레드시트 및 노션 개인 계정 연동
  • 고객정보는 보험인사이트가 아닌 본인의 개인 계정에 저장
  • 고객별 계약, 일정, 상담 및 업무 현황 관리

개인정보 보호를 고려해 고객정보를 사이트에 직접 저장하는 대신,

각자의 스프레드시트 또는 노션에 저장하고 연동하여 사용하는 방식으로 변경했습니다

📌 02. 보장분석 리포트 간편 작성 · 저장 · 인쇄

엑셀 편집이나 복잡한 인쇄 설정 없이, 내용만 입력하면 보장분석 리포트가 완성됩니다

  • 표지부터 리모델링 전·후 비교, 보고서까지 총 7장 한 번에 인쇄
  • 보장금액, 보험료, 보유계약 건수 자동 합산
  • 표지 디자인 12종, 보고서 색상 5종 선택
  • 고객별 보장분석표 저장 및 불러오기
  • 저장한 자료는 언제든 다시 수정하거나 재인쇄
  • 별도 설정 없이 A4 규격에 맞춰 바로 출력

표지 디자인은 앞으로도 계속 추가할 예정입니다

📌 03. 보험증권 속지 최대 30명 일괄 인쇄

  • 명의 / 여름휴가철 / 운전자보험 / 재가보험 / 펫보험
  • 이름 한번만 입력하면 최대 30명까지 일괄 출력

보험증권 속지 종류도 지속적으로 추가할 예정입니다

📌 04. 청구서류 안내장 간편 공유

  • 입원 / 수술 / 통원 / 자부상 / 펫 / 치아 총 6종 제공
  • 고객명과 설계사명을 넣어 맞춤형 안내장 완성
  • 서류내용 수정해서 다양한 안내장으로 이용 가능

📌 05. 고객 상담 일지 · 상담 만족도 조사

① 고객 상담 일지

  • 첫 상담 시 고객정보, 병력, 상담내용 등을 빠짐없이 기록
  • 계약 전 알릴 의무와 병력 확인에 활용
  • 다음 상담이나 보장분석 시 참고 가능

② 상담 만족도 조사

  • 마지막 상담에서 고객 만족도 확인
  • 자연스러운 소개 요청
  • 추가로 필요한 보장을 확인하고 후속 상담에 활용

두 양식 모두 별도의 크기 조정 없이 인쇄 버튼 한 번으로 A4 출력이 가능합니다

📌 06. 스티커 메모 · 캘린더 기능 개선

① 스티커 메모

  • 팝업 단축키: Ctrl + Alt + N
  • 메모 상단 더블클릭 시 엣지 모드 전환
  • 화면 왼쪽 또는 오른쪽 끝으로 이동해도 엣지 모드 전환

② 빠른메뉴 캘린더

  • 기존 캘린더를 스티커 형태로 개편

이번 업데이트는 엑셀이나 PDF 편집이 익숙하지 않은 분들도

복잡한 설정 없이 업무 자료를 쉽게 활용할 수 있도록 준비했습니다

특히 고객별 자료 저장, 자동 계산, 일괄 인쇄 등 반복적인 작업을 줄이는 데 중점을 두었습니다

앞으로도 보험설계사분들의 실제 업무에 필요한 기능과 자료를 꾸준히 업데이트하겠습니다

새로워진 기능들을 직접 이용해 보시고, 개선이 필요한 부분이나 추가되었으면 하는 기능이 있다면 편하게 의견 보내주세요 😊

고객관리 페이지는 승인회원 (인스타그램 구독자)만 이용 가능합니다

인스타그램 구독이 어려우신 분들은 아래 링크에서 별도로 결제 후 이용하실 수 있습니다
