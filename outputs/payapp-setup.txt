페이앱 신규 결제 연동 설정

1. Supabase SQL Editor에서 supabase/migrations/20261016_payapp.sql 실행.
   기존 회원·구독자를 삭제하거나 체크를 초기화하지 않습니다.
2. Vercel 운영 환경변수:
   PAYAPP_USER_ID=판매자 아이디
   PAYAPP_LINK_KEY=연동 KEY
   PAYAPP_LINK_VALUE=연동 VALUE
   PAYAPP_ENABLED=true
3. 변경 코드를 운영 사이트에 재배포.
   고정 운영 주소: https://www.bohuminsight.com
   신규 링크: /subscribe/9900, /subscribe/12000, /subscribe/14000
4. 운영 환경에서 본인이 최초 1건을 직접 결제하고 다음 사항 확인:
   payapp_orders.state=paid, subscribers에 pay_app_code 저장,
   같은 브라우저에서 동일 인스타 아이디로 가입/로그인 후 profiles.status=approved.

PAYAPP_ENABLED는 SQL 적용·운영 환경변수·배포 준비를 마친 후에만 true로 설정합니다.
로컬에서는 결제 요청을 차단합니다. localhost는 페이앱 통보를 받을 수 없습니다.
재요청에 대한 공급자 응답을 받지 못한 경우 중복 결제를 만들지 않도록 같은 아이디 재등록을 막습니다.
실패 시 주문과 페이앱 등록번호를 대조한 뒤 관리자가 재시도 여부를 확인해야 합니다.

현재 범위: 결제 요청, 인증된 성공 통보, 중복 통보 방지, 구독자 등록, 브라우저 소유 확인 후 회원 연결·승인.
실패 통보와 취소 통보는 이벤트로 기록하며, 자동 해지/권한 변경은 아직 적용하지 않습니다.
페이앱 관리자 직접 해지 통보 지원 여부와 결제 실패 재시도 정책은 별도 확인이 필요합니다.
연락처는 수집하지 않습니다. recvphone은 기존 방식과 동일한 대체값을 사용합니다.
비밀키는 소스/Git/브라우저에 넣지 않습니다.
