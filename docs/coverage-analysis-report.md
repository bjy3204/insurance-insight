# 보장분석표 1차 틀

참고 시트: https://docs.google.com/spreadsheets/d/1p8HXXkmDQ1z2BWhrEftwgCGnl1xFiOWlgtQmCni6VjU/edit

## 확인한 스크립트

- 첨부 CRM의 `crmCoverageCreate_`: 고객별 템플릿 파일 복사, 중복 생성 방지, 고객목록에 파일 링크 기록.
- `crmCoveragePersonalize_`: 고정된 예시 고객명을 실제 고객명으로 바꾸고 보고서 제목을 조정.
- 저장소의 `Coverage-Report-Calculations.gs`:
  - `coverageReportRefresh_`: 월 보험료 합계, 보험별 납입 예정/완료, 담보별 합계와 요약표 갱신.
  - `coveragePaymentValues_`: 가입일부터 분석일까지 완료된 개월 수를 계산하고 납입기간 이내로 제한. 원본처럼 월 보험료가 일정하다고 가정한 계산이며 실제 납입내역 조회는 아님.
  - `coverageManualOnlyRow_`: 질병 종 수술비, N대 수술비, 상해 종 수술비는 수동 합계.
  - `coverageAmountText_`: 만원 숫자를 억/만원 표기로 변환. 일상생활배상책임 입력만 억 단위.
  - `coverageSummaryRefresh_`: 상세표에서 담보별 요약표로 값 복사.
- 연결된 시트에서 55개 담보 항목과 두 개의 보고서 탭, 숨겨진 육각형 차트 좌표 시트를 확인. 연결된 Apps Script 프로젝트의 현재 설치 트리거/코드 전체를 직접 조회한 것은 아님.

## 사이트 구현

- 고객·소통 → 보장분석표: 입력 / 인쇄 미리보기.
- 보험 추가, 55개 담보 금액, 보험료와 납입 계산, 종 수술비 수동 합계.
- A4 세로 요약표 1장 + 보험별 상세표(장당 최대 보험 4개).
- 인쇄: 별도 iframe에 보고서만 렌더링하여 브라우저 인쇄. PDF 저장도 브라우저 인쇄창에서 선택 가능.
- 이미지: 동일한 보고서 DOM을 2배 PNG로 생성하고 장별 이미지를 ZIP 한 개로 저장.
- 초기 예시 고객정보/금액은 채우지 않음.
- 현재 작성 내용은 컴포넌트 메모리에만 유지. DB 저장, 고객관리 자동 연결, Google Sheets 동기화는 아직 구현하지 않음. 개인정보를 localStorage에 저장하지 않음.
- 육각형 분석 그래프는 평가 기준이 확인되지 않아 제외. 좌표만으로 보장 충분/부족 점수를 임의로 만들지 않음.

## 후속 저장 연결 시

고객별 보고서 ID, 입력 JSON, 수정 버전/시간을 기존 고객정보와 동일하게 서버 암호화 및 회원 소유권 검사로 보관할 것. 기존 고객 테이블에 평문 담보/건강정보 컬럼을 추가하지 말 것.
